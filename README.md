# 🏥 Sistema de Gestão de Clínicas Médicas

Sistema completo de gerenciamento para **clínicas médicas** desenvolvido em Java.

## 📋 Sobre o Projeto

Este é um projeto de refatoração de um sistema desenvolvido originalmente
em C++ durante a disciplina de Programação II. O objetivo é aplicar boas
práticas de POO, padrões de design e arquitetura limpa.

**Escopo:** Clínicas médicas (médicos com CRM)

## 👥 Funcionalidades

- ✅ Gestão de **médicos** (CRM)
- ✅ Gestão de pacientes
- ✅ Agendamento de consultas
- ✅ Controle financeiro
- ✅ Gestão de planos de saúde
